# sera_base.npz

Body data used by `../sera_character.py`, extracted by `../tools/build_sera_data.py`:
the MakeHuman hm08 base mesh (vertices, UVs, joint helpers, skin weights mapped
to a simplified game skeleton) plus the shape targets the body sliders use.

Source assets are from the MakeHuman project (www.makehumancommunity.org),
whose base mesh and targets are released under **CC0** — free to use in
commercial games with no attribution required (credit is appreciated).
